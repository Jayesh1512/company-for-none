Company for None is a living organization on NEAR: a master agent coordinates specialists, maintains a backlog, and improves the organization after an owner defines its purpose, approved knowledge, policies, and budget. The goal is a business that earns through x402 services and uses its treasury to pay operating expenses and fund improvements.

Our recorded recovery demonstration shows what “living” means. A support agent cannot answer a claims-intake question because its runbook omits contact-preference guidance. Instead of inventing an answer, it escalates. Within a predefined recovery workflow, the backlog delegates a knowledge curator and template developer. The curator updates native JBrain from an approved source; the developer adds the missing contactPreference requirement. A fixed evaluator rejects the old template and accepts the repair. Support retries the same request using the new revisions and completes the intake.

Six real NEAR AI Cloud responses, encrypted and verified in the original process, support this bounded demonstration. Matched provider bills, revision history, and restart evidence make the improvement inspectable.

Separately, the project demonstrates Agent API operations and NEAR mainnet ledger commitments, alongside retained evidence of marketplace x402 purchases. Treasury accounting distinguishes costs, reservations, and intended revenue flows.

Today, recovery is owner-funded; customer-paid delivery and a self-sustaining revenue-to-expense loop remain unproven. The next milestone connects these parts: paid requests fund useful work, while observed failures drive evaluated improvements for subsequent customers.
