# Claim-to-evidence index

Generated by `node scripts/evidence/build.mjs`. This is a curated claim index, not a judge score or an authority to spend.

Run `node scripts/evidence/verify.mjs` for offline integrity, scope consistency, heuristic secret checks, production-root quote signature replay and sanitized actual-AI record consistency. The latter does not replay private TEE/signature/plaintext evidence. Run `node scripts/evidence/run-local.mjs` separately for isolated native-JBrain and controlled pipeline tests. See [evidence guide](evidence/README.md).

Trust scopes: **LIVE_PUBLIC** = original public provider capture; **LIVE_PAID** = sanitized records of the approved actual owner-funded calls; **LIVE_LOCAL** = actual local execution; **CONTROLLED** = injected external facts. Claim status is separate from trust scope. Rebuilding hashes or changing labels cannot manufacture missing live proof.
